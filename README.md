## ✨ Features

- **Developer Aesthetic**: Dark `#141419` minimalist theme with technical grid lines and official HackerRank green (`#05C770`) accents.
- **Cinematic Entrance Sequence**:
  - Technical terminal prompt `$ initializing campus_crew` with deliberate keystrokes.
  - Natural execution pause with cursor blinking.
  - Staggered silk-ease typography reveal (`Satoshi` & `Departure Mono`).
  - Radar status pulse on the launch announcement.
- **Dynamic Mouse Spotlight**: Purely cursor-activated ambient illumination across the grid.
- **Responsive & Accessible**: Seamless scaling on desktop, tablet, and mobile with full `@media (prefers-reduced-motion: reduce)` support.
